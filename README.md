# Water Rocket Lab — public demo

Try the interactive physics experiment: https://dstiv-ai.github.io/water-rocket-demo/

Design a water rocket, predict its flight, and compare with clearly labelled fictional launch data. No sign-in, backend, AI calls, or personal records. All calculations run in your browser.

Designed and built by Dimitrios Stivaktas.

This repository contains only the built static demo. The classroom application and project source are not published here. Predictions are educational estimates, not launch approval.
